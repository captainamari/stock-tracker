# BUY 策略与网页信号展示

## BUY v1：三个条件必须同时满足

策略 ID：`buy_us`。使用已收盘的日线 OHLC 与原始成交量，独立于 Stage 2、收缩候选、逆势观察和 Checklist。不需要 252 日历史，不要求突破横盘最高价；基准 SPY/QQQ/IWM/VIX 不进入个股榜单。

| 条件 | 默认规则 | 参数 |
|---|---|---|
| C1 买入池 | 信号日前 **30 个交易日** `(最高 High / 最低 Low - 1) × 100 ≤ 10%`，**且**此前最近20个完整交易日均量 / 再前20个完整交易日均量 ≤ 0.8 | `sideways_sessions=30`, `max_range_pct=10`, `quiet_sessions=20`, `quiet_reference_sessions=20`, `max_quiet_ratio=0.8` |
| C2 放量 | 信号日成交量 / 此前20个完整交易日均量 **≥3** | `volume_sessions=20`, `min_volume_multiple=3` |
| C3 向上 | 信号日 **Close > Open 且 Close > 前一交易日 Close** | 严格大于，平价不通过 |

信号日不参与横盘和任何均量基准；未来数据不参与计算。横盘使用最高价/最低价范围，并非收盘价标准差。低量窗口与横盘窗口独立：横盘30日，低量仍20日对比前20日。它们可以在配置文件中分别微调。

只满足 C1 时标为“池内待触发”；C1/C2/C3 全通过才显示 BUY，参考价为该日**复权收盘价**，不代表次日可成交价格。BUY 分数是通过条件数 / 3 × 100（100分才满足），不是胜率。BUY 默认不归入“接近”列表；买入池状态在结果及详情中可见。

## 数据完整性与参数

配置：[`config/buy.json`](../config/buy.json)。`version` 目前为1；非法、缺键、非有限数值或互相矛盾的阈值会阻止任务计算。结果保存 `buy-v1`、完整参数和参数指纹，详情页显示本批次参数。修改配置后只影响后续新计算批次，不覆盖已发布历史。

以 XNYS 交易日历对齐日期。横盘检查连续交易日；成交量窗口排除提前收盘日，信号日若为半日则不判断 BUY。完整默认历史至少需要信号日前40个完整交易日，加上信号日本身；窗口内缺失价格、无效 OHLC、缺量、非正成交量、重复日期或来源质量异常均不能确认为信号。不能通过跳过缺失交易日凑足样本。

该规则是日终筛选，无法识别日内触发时点。数据源使用复权 OHLC 和原始成交量；拆股等事件可能影响量比较，不能据此推断真实机构资金流。项目没有自动交易或下单行为。

## 网页五项调整

1. 保留导航、卡片、配色与表格。概览及历史市场背景增加 SPY/QQQ/IWM 的当日量比、量价分类、近10日结构和涨跌日均量比；SPY/QQQ 显示今日派发及近25日有效派发次数，保留均线距离、广度和有效分母。VIX 不套用成交量指标。
2. 列表代码/名称搜索忽略大小写并去除首尾空格，分页回到第一页；不删除代码中的合法符号。API 和前端一致，直接代码路径亦按既有规则规范化。
3. 行情与策略两种列组合均展示统一量价依据。桌面在涨跌幅之后展示量价列，手机将量价放在代码下方。详情展示同批次量价和 BUY 参考价/参数。
4. 所有页面策略计数按钮使用 `策略名[数量]`。统计完整所选范围，不受搜索、筛选和分页影响；策略可重叠。旧批次未计算 BUY 时显示 `BUY[—]`，不会误报 `BUY[0]`。
5. 已确认变化默认收起，摘要分别统计变化条数、去重代码数、新增和退出数。展开后按类型/策略筛选，每页10条，代码链接保留原批次。缺少前后有效数据的比较单列提示；没有变化时显示简短状态。跨策略同一代码可贡献多条变化。

RVOL 与涨跌日均量比、派发日使用不同口径，见 [量价规则](VOLUME_PRICE_AND_DIGEST.md)。旧批次未计算、数据不足、样本不足和中性/混合分别表达；页面 GET 只读保存结果，不现场补算。策略分与量价结论分开展示。

## 通知与排序

默认通知策略为 Stage 2、收缩候选、逆势观察、BUY；Checklist 可通过私人配置的 `strategies` 显式加入。已有显式列表需要增加 `buy_us` 才会包含 BUY。每个策略依然最多10个符合项，按策略分、通过条件数、代码排序；BUY 全通过时分数相同，因此代码为稳定的最终排序项，不暗示额外强弱排名。

BUY 通知包括横盘振幅、低量比、放量倍数、开盘/收盘及参考价，同时保留通用量价结构。前一交易日没有有效 BUY 结果时，不确认“新增”；退出不等于自动卖出。

## 用已有行情生成新计算批次

```sh
python -m lib.cli recalculate
```

仅服务器 CLI 可调用，无公开写接口。拒绝与排队/运行中的更新重叠；沿用当前发布批次的行情日期、每个标的输入版本及指数名单快照，在独立新批次计算当前规则后原子发布。失败保留原发布指针。不会下载行情、改旧报告、发送/补发通知，也不会将旧行情标成今天数据。部署前备份数据库，暂停任务调度；完成后恢复调度。

测试覆盖三条件、等号边界、30日窗口、缺口/半日、无未来数据、参数指纹、短历史独立计算、大小写搜索、公开投影、通知以及原批次不可变性。
