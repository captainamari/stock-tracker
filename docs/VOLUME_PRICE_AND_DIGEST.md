# 量价分析与收盘通知

本规则用于观察，不是经过收益回测验证的买卖系统。量价说明独立于现有四个策略，不改变信号、评分、入选或退出条件。

## 数据、保存与历史

- 来源：现有 yfinance 日线 OHLCV，复权 OHLC 与来源提供的成交量。仅使用目标交易日及以前的数据，不调用新数据源。
- 计算入口：`lib/strategy_service.py` 的行情计算阶段；实现：`lib/volume_price.py`。
- 每只股票结果保存在 `daily_results` 的 `technical.metrics.volume_price`，包括公式版本 `volume-price-v1`、完整参数、参数指纹、每日观察和汇总。SPY/QQQ/IWM 的结果同时进入冻结市场背景。
- 日报只读取保存结果，不重新计算。新公式仅用于新批次；旧批次没有该字段时显示“旧批次未计算，等待新批次”。旧报告、投递内容与重试分段不改写。
- 参数文件在一次行情计算开始时读取。Docker 部署需要重建镜像；原生部署应在任务空闲时更新并重启 worker，避免同一运行期间替换代码或配置。

## 可调整参数

编辑 [`config/volume-price.json`](../config/volume-price.json)，保留 `version: 1`。参数错误会明确失败，不能悄悄采用不同默认值。

| 参数 | 默认 | 含义 |
|---|---:|---|
| baseline_sessions | 20 | 当天之前的完整交易日均量窗口，不含当天；排除半日交易 |
| window_sessions | 10 | 多日观察窗口，按交易日而非自然日 |
| high_volume | 1.2 | 相对量大于等于此值为放量 |
| low_volume | 0.8 | 相对量小于等于此值为缩量 |
| flat_pct | 0.2 | 日涨跌幅绝对值不超过此百分数为平盘 |
| min_side_days | 2 | 上涨日和下跌日至少各有多少个，才能判定组合 |
| min_pattern_days | 2 | 偏多/偏空组合中的两类事件各自至少出现几次 |
| bull_ratio | 1.2 | 偏多需要的上涨日均量/下跌日均量下限 |
| bear_ratio | 0.8333333333 | 偏空需要的上涨日均量/下跌日均量上限 |
| trend_fast / trend_slow | 20 / 50 | 价格趋势的快、慢收盘均线 |
| slope_sessions | 5 | 快均线与此前多少个交易日比较方向 |

以上阈值是初始观察参数，不代表最佳值或已验证胜率。修改分类逻辑时升级代码中的 `RULE_VERSION`，修改参数会自动改变 `parameter_id`。参数验证约束：正数、放量阈值>1>缩量阈值、快线<慢线、窗口能容纳两边最低样本。

## 公式与判定

1. 涨跌幅 = `(今日复权收盘 / 前一交易日复权收盘 - 1) × 100`，比较前收，不按当日开收阴阳线分类。
2. 相对量 = `今日成交量 / 此前 baseline_sessions 个完整交易日平均成交量`。这不是盘中量比，也不是收缩策略已有的10/50日均量比。
3. 当天分类：放量上涨、缩量上涨、正常量上涨、放量下跌、缩量下跌、正常量下跌、平盘、未知。先判平盘，再根据涨跌方向与相对量分类。
4. 汇总最近 `window_sessions` 个交易日，各类别相加等于窗口长度；保存日期顺序。未知项不当作缩量或平盘。
5. 涨跌日均量比 = `上涨日原始成交量的算术平均 / 下跌日原始成交量的算术平均`。两边均须满足 `min_side_days`；平盘和未知不参与。另保存两组平均相对量 `up_mean_rvol/down_mean_rvol`，它们不是该比值的分子分母。
6. 偏多：放量涨、缩量跌各至少 `min_pattern_days` 次；放量涨次数>放量跌次数；涨跌日均量比≥`bull_ratio`。
7. 偏空：放量跌、缩量涨各至少 `min_pattern_days` 次；放量跌次数>放量涨次数；涨跌日均量比≤`bear_ratio`。
8. 有足够样本但不满足任一组合→混合；任何窗口日未知或两侧样本不足→未知。只有上涨日不能据此判“偏多”。
9. 价格趋势另行计算：`收盘 > MA20 > MA50` 且 MA20 高于5个交易日前→上升；反向→下降；其他→震荡；历史缺失→未知。这里没有实现摆动高低点确认，均线趋势也不等于支撑位守住。
10. 顺序描述：最新连续若干日均为缩量跌，且此前同窗口有放量涨→“放量上涨后，最近N日连续缩量回调”；反向→缩量反弹。窗口含未知不作顺序判断。这是时序描述，不证明因果或支撑有效。

“趋势上升·量价偏空”允许出现，明确表达冲突；不将价格方向和量能证据强行合成买卖指令。

## 数据边界

- 对齐 XNYS 交易日，不把缺一天后的累计涨跌当单日涨跌；均量窗口缺失或成交量为0、负数、非有限数时输出未知。
- 半日交易保留在观察窗口中并标记未知，不以按分钟线性放大方式猜测全天量；均量基准跳过半日。窗口含半日时组合结论暂停，价格趋势可继续展示。
- SPY/QQQ 是 ETF 自身成交量，不代表其全部成分股总量；VIX 不进行股票成交量分析。
- 当前历史存储没有独立的拆股事件和成交量调整因子。本版本不声称识别所有拆股异常，也不把异常成交量自动判断为机构行为；来源量口径若发生变化应先核查并修复输入。历史修订继续由原采集流程处理。
- 日线不能得到真实机构流入/流出，也不提供精确盘中订单流。派发日仍沿用既有项目规则，与 RVOL 分类不同：跌幅至少0.2%、成交量高于前日，滚动25日并按现有上涨5%规则失效。

## 通知格式与筛选

顺序为市场概况 → 今日变化 → 各策略 Top 10 → 数据异常与公开入口。

- 默认三榜：`stage2_us`（趋势）、`contraction_us`（收缩）、`bottom_fisher_us`（逆势）。计算层仍保留全部四策略。
- 可在私人日报 JSON 添加 `strategies`，例如 `["stage2_us","contraction_us","bottom_fisher_us","checklist_us"]`；顺序即通知顺序。必须非空、无重复、仅使用支持的 ID。
- 仅从私人通知 `symbols` 中筛选；浏览器收藏和市场广度范围不受影响。
- 入榜须行情和该策略均有效且 `is_signal=true`；评分降序、通过条件数降序、代码升序。持有标记或其他策略变化不抢排名。缺分数排末尾。
- 每榜最多10只，不足不补位；零符合和数据不足分别说明。接近符合只显示数量。多个榜可重复出现，附多策略标记，不相加各策略分数。
- 新增/退出只比较相邻交易日双方有效结果；“新增符合”不是“新进入前十”。退出单独显示，不因退出榜单而丢失。
- `compact`：每只股票保留价格、涨跌、评分、量价摘要和窗口计数，前三名再显示策略关键指标。`standard`：仍最多10只，增加每只股票的完整量价计数、样本数和时序描述。二者均不附整份名单每日行情。
- 市场区显示 SPY/QQQ 量价、均线位置、今日是否派发及25日有效次数；IWM/VIX、广度有效分母及缺失。数据不完整时不生成完整市场判断。
- 市场评分与状态可能不同：VIX、SPY低于MA200、派发日达到阈值可限制状态；新批次保存原因。所有阈值沿用原市场模块，量价新模块不覆盖市场状态。
- 消息沿用 Hub 的3000字符保守分段，按空行优先，重试复用冻结段。私人报告不开放到公开网页，末尾仍为公开概览。

## 验证与调参流程

```sh
python -m pytest -q tests/test_volume_price.py tests/test_personal_reports.py tests/test_guest_digest.py
python -m pytest -q
python -m scripts.send_daily_report --config /etc/stock-tracker/daily-report.json --dry-run
```

先记录参数版本与观察期，再调整一个参数并比较后续结果；若要验证收益效果，应另做包含交易成本和样本外数据的回测。发布后下一次正常行情批次会产生新量价字段；没有数据迁移或重写历史。预览旧批次只验证模板兼容，不等于新量价计算已在该批次完成。不要为测试模板使用 `--manual-reissue` 或绕过投递防重。
