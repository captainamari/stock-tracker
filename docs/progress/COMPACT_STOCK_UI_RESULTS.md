# 紧凑股票 UI 改造验收

日期：2026-11-12。开发分支：`codex/compact-stock-ui`。基线及提交前再次拉取的 `origin/main` 均为 `a32533e9099278b10a313f048d4fe90f729dc9fa`。使用新隔离 checkout；未修改原工作区，无适用的 AGENTS.md。没有部署、生产数据操作或真实通知。

## 问题与实现

- 原 `#guest` 内部缺少统一间距；三项 context 使用四列、四项指数使用五列。现统一桌面 20px / 手机 16px 主板块间距，内部工具栏更紧凑，网格与内容数一致。
- 三页原股票卡片替换为 `stock-table.js` 的共享语义化表格、列定义、价格/状态格式化。策略名放列头，普通行 50px；涨跌有符号、颜色及零值中性。策略匹配/接近/未匹配/缺失与基准不适用分别显示。详情及日报历史展开保留。
- 四张重复候选卡替换为可点击策略计数条；计数来自完整关注/公开范围，在搜索及筛选之前计算，范围说明可展开。确认变化单独展示，比较缺失明确不能确认，不以分数推断信号。
- 桌面默认策略列，手机默认行情列并折叠高级筛选；表格单一滚动容器，只有身份列固定，表头在容器内定位。搜索、策略、状态、排序、每页数量与分页联动；列头状态与筛选器一致，评分排序需指定策略。
- 收藏星标提供读屏名称、pressed 状态和键盘焦点。“添加股票”为主要操作；管理菜单收纳导入导出、确认恢复/清空。编辑模式只在完整收藏顺序且无筛选时开放，上下移始终操作完整保存列表。
- 首次加载占位；后续保留旧内容、标记忙碌。AbortController 加请求序号防止旧响应覆盖；失败保留最近结果并提供 Retry。发现页收藏只更新星标，列表更新恢复操作焦点和滚动；状态通过 URL 与会话存储恢复。
- 概览保留紧凑市场状态、指数及局部有效广度，即使整体判断缺输入仍显示有效指标。关注页移除重复背景；发现页采集范围移到帮助。日报突出日期/邻接导航，历史背景折叠并保留旧版广度说明。
- 详情星标放代码旁，行情集中展示；图表 1M/3M/6M/1Y/全部只切片已保存日线，处理月末/闰年、短历史、空数据，不填补缺口。策略摘要先于完整条件；常用指标增加名称/单位。返回来源白名单防止外部地址、反斜杠和控制字符，保留查询及滚动。
- 后端仅补充既有分数、冻结前日比较和按批次 revision watermark 读取的价格来源/口径；未改策略、采集池、历史报告、通知流程或数据库 schema。旧 Python 小图展示函数及卡片样式无生产调用，移除后将缺口连线检查迁移至真实共享 SVG 渲染器。
- 静态资源沿用 defer 顺序 `watchlist → stock-table → main`，版本 query 更新，无构建系统或新运行依赖。中英文 README、常用指标名称和界面文案同步。

## 数据边界

默认九只、`stock-tracker-watchlist` 键及 `{version:1,symbols:[...]}` 格式保持；主动清空不恢复默认。损坏、权限受限、配额满和无效导入不会覆盖已有有效收藏。标普500与纳斯达克100并集及基准采集、有效/应统计/缺失分母继续独立于浏览器筛选。私人日报及其独立发送脚本未变。

验收数据库只由拒绝覆盖既有库的 `tests.preview_fixture` 生成，含两个发布交易日；所有价格明确标记 `synthetic_test`。另通过隔离浏览器 HTTP 响应注入零涨跌、长名称、断开网络和延迟响应。没有下载新的真实市场行情，不能将本验收作为真实全市场行情完整性或性能结论。历史日报、来源、图表均锁定原批次；新修订不能污染原报告。存储被禁用时，只能保证当前标签页收藏操作，无法保证刷新后保存或返回滚动恢复。
